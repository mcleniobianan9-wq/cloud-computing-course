# Reflection

This laboratory activity helped me understand the basics of working with a cloud-based Linux environment. I learned how to access KillerCoda, navigate the Linux terminal, check basic system information, and organize files and directories.

I also learned the importance of documenting technical activities using Markdown and GitHub. Creating a GitHub repository gave me a place to store my laboratory files, screenshots, and other activities in an organized way.

One of the useful parts of the activity was learning basic Linux commands and understanding information such as the operating system, CPU, memory, and disk space. These skills are important because Linux is commonly used in cloud environments.

Overall, this laboratory gave me a better understanding of how Linux, cloud computing, and GitHub can work together. It also helped me become more comfortable with documenting my work and maintaining a technical portfolio.
