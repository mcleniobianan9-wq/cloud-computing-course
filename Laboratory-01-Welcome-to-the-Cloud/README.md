# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduced me to a cloud-based Linux environment using the KillerCoda Playground. I explored Ubuntu Linux, practiced basic Linux commands, collected system information, and documented my activities in GitHub.

## Objectives

- Access and explore a Linux environment using KillerCoda.
- Check basic system information.
- Practice Linux commands.
- Organize files and directories.
- Document my work using Markdown and GitHub.

## Activities Performed

- Launched an Ubuntu 24.04 Linux Playground.
- Checked the Linux operating system information.
- Checked CPU information.
- Checked memory usage.
- Checked available disk space.
- Created and organized Markdown files.
- Uploaded screenshots and documentation to GitHub.

## Linux Commands Used

- `cat /etc/os-release` – checks the Linux distribution.
- `uname -r` – checks the kernel version.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.

## Skills Learned

Through this laboratory, I learned how to work with a Linux environment, use basic Linux commands, collect system information, organize files, and document technical activities using GitHub and Markdown.
