# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, analytics, and other business needs.

## 2. Global Infrastructure

Azure has a global infrastructure consisting of regions and availability zones. These locations allow organizations to deploy applications and services in different geographic areas.

## 3. Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtual servers that can run applications and operating systems in the cloud.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as files, images, and documents.

### Azure Virtual Network

Azure Virtual Network allows users to create private networks and control communication between cloud resources.

### Microsoft Entra ID

Microsoft Entra ID is an identity and access management service used to manage users and access to cloud resources.

## 5. Three Advantages

1. Azure integrates well with Microsoft products and technologies.
2. Azure provides many cloud services for organizations of different sizes.
3. Azure has a global infrastructure that supports applications and services around the world.

## 6. Typical Enterprise Use Cases

Organizations can use Azure for hosting websites and applications, running virtual machines, storing business data, managing identities, databases, analytics, and integrating existing Microsoft environments with cloud services.
