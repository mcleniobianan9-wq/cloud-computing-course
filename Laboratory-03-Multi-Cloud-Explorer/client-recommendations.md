# Cloud Platform Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for the startup because it provides many cloud services that can support a new mobile application. The startup can begin with smaller resources and increase them as the application grows. AWS also provides services that can help the company build, store, and manage its application. This makes it a flexible option for a growing startup.

**Recommended Services:**

* Amazon EC2 – Compute
* Amazon S3 – Object Storage
* Amazon RDS – Database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies. This can make it easier for the university to connect its current systems with cloud services. Azure can also support the university as it gradually migrates services to the cloud.

**Recommended Services:**

* Azure Virtual Machines – Compute
* Microsoft Entra ID – Identity and Access
* Azure Storage – Cloud Storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud Platform is a suitable choice for an AI research company because it provides services for Artificial Intelligence, Machine Learning, and high-performance computing. These capabilities can support researchers developing AI and ML applications. GCP also provides services for data processing and modern application development. This makes it a strong option for AI-focused workloads.

**Recommended Services:**

* Compute Engine – Virtual Machines
* Google Kubernetes Engine (GKE) – Kubernetes
* Cloud Storage – Data Storage

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable choice for a global e-commerce company because it provides scalable cloud infrastructure for applications serving customers in different locations. The company can increase or decrease resources based on demand. AWS also provides services for computing, storage, databases, and networking. These capabilities can help support a highly available online shopping platform.

**Recommended Services:**

* Amazon EC2 – Compute
* Amazon S3 – Object Storage
* Amazon RDS – Database
* Elastic Load Balancing – Load Balancing

## Multi-Cloud Decision Matrix

| Business Requirement    | Recommended Platform  | Justification                                                                                                                              |
| ----------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Startup Company         | AWS                   | AWS offers many services and allows a startup to scale its resources as the business grows.                                                |
| Enterprise Organization | AWS                   | AWS provides a wide range of services that can support different enterprise workloads and requirements.                                    |
| Microsoft Environment   | Microsoft Azure       | Azure is recommended because it integrates well with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID. |
| AI / Machine Learning   | Google Cloud Platform | GCP is a strong choice for AI and Machine Learning workloads and provides services for modern AI applications.                             |
| Kubernetes Deployment   | Google Cloud Platform | GCP is a strong option for Kubernetes deployment through Google Kubernetes Engine (GKE).                                                   |
| Global Web Application  | AWS                   | AWS provides global infrastructure and scalable services that can support web applications serving users in different locations.           |
