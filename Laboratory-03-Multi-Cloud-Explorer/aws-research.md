# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides many services for computing, storage, networking, databases, security, and other cloud needs. It allows organizations to use IT resources through the cloud instead of maintaining all infrastructure on their own.

## 2. Global Infrastructure

AWS has a global infrastructure made up of Regions and Availability Zones. These locations allow customers to deploy applications closer to their users and improve availability and reliability.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can use the console to create, configure, monitor, and manage cloud resources.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve files and data.

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create and manage a logically isolated network in AWS.

### AWS IAM

AWS Identity and Access Management (IAM) is used to manage users, permissions, and access to AWS resources.

## 5. Three Advantages

1. AWS provides a wide range of cloud services for different types of workloads.
2. AWS allows organizations to scale their resources based on their needs.
3. AWS provides a global infrastructure that supports applications in different locations.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for web and mobile applications, data storage, backup and disaster recovery, databases, data analytics, and other business workloads.
