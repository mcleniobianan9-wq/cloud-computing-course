# Google Cloud Platform Research

## 1. Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers cloud services for computing, storage, networking, databases, data analytics, artificial intelligence, and other technology needs.

## 2. Global Infrastructure

Google Cloud has a global infrastructure consisting of regions and zones. This allows organizations to deploy applications and services in different geographic locations.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## 4. Four Core Services

### Compute Engine

Compute Engine provides virtual machines that can be used to run applications and workloads in the cloud.

### Cloud Storage

Cloud Storage is an object storage service used to store and retrieve different types of data.

### Virtual Private Cloud

Google Cloud VPC provides networking capabilities that allow organizations to connect and manage their cloud resources.

### Cloud Identity

Cloud Identity provides identity and access management capabilities for users and organizations.

## 5. Three Advantages

1. GCP provides strong capabilities for data analytics and artificial intelligence.
2. GCP provides a global cloud infrastructure.
3. GCP provides services that support modern applications and container-based workloads.

## 6. Typical Enterprise Use Cases

GCP can be used for application hosting, data analytics, artificial intelligence and machine learning, data storage, containerized applications, and other enterprise workloads.
