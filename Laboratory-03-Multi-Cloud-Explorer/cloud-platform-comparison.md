## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, networking, databases, security, and many other areas. Its large selection makes it suitable for organizations with different types of cloud requirements.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the best choice for organizations that already use Microsoft technologies. It works well with products and services such as Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes-related workloads. Google has extensive experience with data, AI technologies, and Kubernetes.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide range of services and can support different types of applications and business requirements. It also provides services that can be used by both small organizations and large enterprises.
