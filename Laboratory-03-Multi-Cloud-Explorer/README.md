# Laboratory 03 – Multi-Cloud Explorer

This laboratory activity explores and compares Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Objectives

- Explore AWS, Microsoft Azure, and GCP.
- Identify their core cloud services.
- Compare cloud platforms.
- Recommend cloud solutions for different business scenarios.
- Use Linux and KillerCoda to understand cloud virtual machines.

### Cloud Hosting Options

If this Linux server were migrated to the cloud, it could be hosted using virtual machine services from AWS, Microsoft Azure, and Google Cloud Platform.

* **AWS:** Amazon EC2
* **Microsoft Azure:** Azure Virtual Machines
* **Google Cloud Platform:** Compute Engine

These services provide virtual machines that can run Linux-based operating systems and applications in the cloud.
